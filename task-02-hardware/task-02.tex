\section*{Avionics System Design}

This documentation is on choosing the right components for a standard quadcopter UAV (Unmanned Aerial Vehicle) drone used for photography.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.55\textwidth]{images/Quadcopter.png}
    \caption{\href{https://www.zenatech.com/7-essential-drone-parts-you-need-to-know/}{drone parts}}
    \label{fig:aircraft}
\end{figure}

\begin{itemize}
    \item \textbf{Flight controller (FC):} drone brain, has built-in gyroscope and accelerometer for stability, speed control.
    \item \textbf{Receiver:} The receiver picks up control signals from your radio transmitter.
    \item \textbf{ESC:} converts the FC's low-power signals into the high-current power that brushless motors need.
    \item \textbf{GPS:} Important for automated navigation, like waypoint tracking and return-to-home.
    \item \textbf{FPV camera:} feeds video to the VTX.
    \item \textbf{VTX:} sends the live camera feed to your ground control station.
    \item \textbf{Magnetometers:} assist with navigation by detecting the Earth’s magnetic field, improving directional accuracy.
    \item \textbf{Barometers:} estimate altitude by detecting air pressure, enabling precise height control and smoother landings.
\end{itemize}

\subsection{Sensors and Protocols}
Here are all sensors usable with the flight controller connections and protocol mentioned:

\textbf{Connections to Flight controller}
\begin{itemize}
    \item \textbf{Receiver RX (UART):} Connects to the FC serial port, ExpressLRS (ELRS) receiver, which uses UART protocol and is bi-directional \href{https://ardupilot.org/copter/docs/common-smartap-pdb.html}{Receivers}.
    \item \textbf{GPS Module (UART):} Transmits position and navigation data to the FC via high-speed serial UART.
    \item \textbf{Magnetometer / Compass (I2C):} Measures heading orientation using a 2-wire I2C bus suitable for low-data-rate sensors.
    \item \textbf{Barometer (SPI / I2C):} Measures atmospheric pressure for altitude estimation; interfaced internally via fast SPI or I2C.
    \item \textbf{Telemetry Radio (UART):} Provides a two-way serial link via UART for real-time flight data and GCS communication.
    \item \textbf{SBC Companion Computer (UART):} Communicates high-level mission commands and video data with the FC using the MAVLink protocol.
    \item \textbf{ESC / Motors (PWM / DShot):} Transmits motor speed commands directly from the FC output channels.
\end{itemize}

\section{Battery Calculations and Flight Time}

\subsection{Current Consumption Breakdown}
By referring to Table~\ref{tab:parameters}, the overall current drawn from the system components is:
\begin{itemize}
    \item FC = $800\,\text{mA} = 0.8\,\text{A}$
    \item Raspberry Pi = $1200\,\text{mA} = 1.2\,\text{A}$
    \item GPS = $200\,\text{mA} = 0.2\,\text{A}$
    \item Receiver = $1000\,\text{mA} = 1.0\,\text{A}$
    \item Telemetry = $100\,\text{mA} = 0.1\,\text{A}$

    \item Avionics (FC + Raspberry Pi + GPS + Receiver + Telemetry) = $0.8 + 1.2 + 0.2 + 1.0 + 0.1 = 3.3\,\text{A}$
    \item 4 $\times$ Velox Motors (Cruise/Hover draw) = $4 \times 3.0\,\text{A} = 12.0\,\text{A}$
    \item \textbf{Total Cruise Current Draw ($I_{\text{total}}$):} $3.3\,\text{A} + 12.0\,\text{A} = 15.3\,\text{A}$
\end{itemize}

\subsection{Battery Sizing and Flight Time Estimation}
Selected Battery: \textbf{Li-ion 4S2P (4200 mAh, 14.8 V, 45 A Continuous Output)}

\begin{itemize}
    \item \textbf{Flight Time ($T_{\text{flight}}$):}
    \begin{equation}
        T_{\text{flight}} = \frac{\text{Battery Capacity (Ah)}}{I_{\text{total}}} \times 60 = \frac{4.2\,\text{Ah}}{15.3\,\text{A}} \times 60 \approx 16.4\,\text{minutes}
    \end{equation}
    
    \item \textbf{Discharge Safety Check:}
    The battery continuous discharge capability is $45\,\text{A}$, which easily covers the continuous cruise requirement ($15.3\,\text{A}$).
\end{itemize}

\subsection{Fuse Selection}
A \textbf{40 A Blade Fuse} was chosen to protect the system against short circuits, while safely handling the normal $15.3\,\text{A}$ cruise current.
